# App identity

The My Fan Control mark uses a four-blade orange/gold fan with fresh-green cooling airflow, on a deep-black macOS rounded-square tile. It is distinct from the SkyTruong ST monogram and from other fan-control app icons.

Palette reference supplied by the owner: SkyTruong orange `#FF5A00`, gold `#FFC400`, fresh green `#80F23E`, black `#030303` and white `#FFFFFF`. Artwork gradients contain intermediate colors.

- `AppIcon.png`: final 1024×1024 RGBA app artwork with transparent outer padding.
- `AppIcon.icns`: native macOS icon, 16–1024 pixel representations.
- `icon-preview.png`: legibility comparison at several sizes.

Raster artwork was generated and edited through the configured SkyTruong Responses image tool, then inspected and prepared locally. The final file is a raster asset, not a claimed vector master. No original SkyTruong brand files are redistributed here.
