# Preset activation upgrade

The 0.1 preview's preset flow was incomplete. Selecting a menu item only copied fields into a form, generated a new policy UUID when applying, appended duplicate presets on save, disabled Apply before authorization, and cleared action errors during telemetry polling. The first physical test also exposed a broken detached helper launch and missing Apple Silicon thermal-controller handoff.

The upgrade provides a visible saved-preset library, stable IDs, update/copy/delete actions, explicit target selection, a fixed visible Apply area, integrated user-initiated macOS authorization, and separate persistent operation/telemetry status. Existing presets and schedule snapshots remain compatible.

The privileged service runs under its authorized launcher while the GUI handshakes asynchronously. It reports a protocol version, active policies separately from pending restoration, and startup failures. Legacy service retirement verifies the endpoint peer, executable identity and system-owned fan state before stopping that service; stale sockets are removed only after bounded ownership/inode/connection checks.

For Apple Silicon machines exposing `Ftst`, a manual request takes the thermal-controller handoff gate before issuing the bounded mode/target pair. When the gate is released, mode 1 can be used by thermalmonitord itself and is not reported as a user-forced fan. All owned modes and targets are cleared before the final owned fan returns the gate to macOS; failure and lease cleanup use the same path. Gate changes wait for asynchronous firmware readback. Compatibility behavior is based on the credited MIT Stats implementation, with bounded retries and explicit readback.

46 automated tests cover saved-preset persistence/identity/update, permission cancellation/failure, protocol migration, operation-error retention, per-fan/group policies, handoff sequencing and cleanup, schedules and injected failures. Live M4 Pro checks observed both fans near 2500 RPM after applying the saved preset, and around 2969/2944 RPM for the 2950 RPM preset. After the final automatic-restoration fix, targets returned to 1350/1458 with measured speeds near 1345/1458 and both fans reported automatic. A timed run was exercised before that final restoration fix; repeating timer expiry with the final fix and physical sleep/wake testing remain pending. Other Mac models are not physically verified.

The schedule editor now uses an explicit label/value layout and scrollable content with a fixed action footer, replacing the macOS Form layout that overflowed the sheet. Countdown, date and weekly inputs retain the selected schedule identity. Minute values can be typed directly. Visual checks covered Vietnamese/English and light/dark appearances using app-local QA launch arguments; system preferences were not changed. Localization checks pass for 233 matching keys.
